# BI dashboard

Maps to: FR-5 | Week: 7, 9

This project doesn't prescribe a specific BI tool (Metabase, Looker Studio,
or equivalent — see the Project Charter's reference tech stack). Use this
folder for whatever your tool supports committing to version control:

- Metabase: exported dashboard/question definitions (JSON), or a note on
  which Metabase instance/collection to look at if it's not exportable.
- Looker Studio: a link to the published dashboard (Looker Studio reports
  aren't git-friendly) plus a screenshot for the record.

At minimum, this folder should contain enough for someone to find or
recreate the dashboard without asking you directly (see the Definition of
Done in the Project Charter).
